# 原始设计材料

本目录用于保存用户提供的原始设计文件快照，作为后续设计演进的来源依据。

- 00-总述.md
- 01-重点拆分与逐点思考.md
- 02-初始化底座与目录构筑.md

规则：

1. 原始快照原则上只读，不在此处直接修改。
2. 方案调整写入 docs/product、docs/architecture、docs/quality 或 ADR。
3. 若新方案与原文不同，必须记录差异、原因、状态和影响，不静默覆盖。
4. 原始材料中提及但未随本轮提供的 DESIGN.md、CAPABILITIES.md、FOCUS.md、SYNC.md 等详细文档，暂不视为已审阅；待取得后补充对照。
