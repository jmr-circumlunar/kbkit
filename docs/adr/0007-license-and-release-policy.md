# ADR-0007：License 与公开发布策略

- 状态：Proposed
- 日期：2026-11-17

## 背景

当前 GitHub 仓库为 public，但尚未有用户确认的开源授权协议。仓库的 Python 元数据曾临时写入 MIT，这不应被误认为用户已经选择 MIT。

## 提案

- 在用户明确选择前，不添加 LICENSE 文件，不宣称项目采用 MIT 或其他许可证。
- 在对外发布、接受外部贡献或分发二进制前，确认 License、版权声明、第三方引用和贡献条款。
- README 与 pyproject 的 License 元数据必须与最终 LICENSE 文件一致。

## 待决

用户希望闭源自用、允许内部使用、开源协作还是商业双许可？由用户确认后再更新。
