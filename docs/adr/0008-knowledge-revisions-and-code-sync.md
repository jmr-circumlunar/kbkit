# ADR 0008：知识依赖、设计版本和代码同步

状态：采纳。适用于本地知识库和用户绑定的本地 Git 仓库。

普通链接用于导航。用显式依赖记录知识判断依据的页面及其哈希，避免只因链接存在就把普通页面连锁标为失效。每次复核保存当前页与依赖基线。依赖变化、缺失或失效时，下游页退出默认检索。库内状态可追溯至具体原因。复核后的设计版本保留可读取快照，正式设计页继续使用原路径。

定时器由 Agent 宿主设置。CLI 和 MCP 共用维护入口。每次运行扫描绑定的本地 Git ref，根据授权路径更新固定的生成页，记录提交、路径和可机械验证的实现符号。作用域内容未变时保持原页。生成页被人工改动时保留该文件并标记冲突。使用代码仓库查询具体实现。外部文件、服务和会话的自动事实刷新另行确认。

知识基线、代码绑定和历史属于库运维数据。保存于 `.kbkit/knowledge.json` 和 `.kbkit/history/`，随库备份。SQLite 搜索索引仍可独立重建。未登记的普通笔记继续可检索。已归档、已废弃和已知失效页通过显式历史查询或包含非当前结果的检索查看。
