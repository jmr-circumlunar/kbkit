# ADR-0005：Markdown 最小解析与字节保留写回

- 状态：Proposed
- 日期：2026-11-17

## 背景

项目要求零第三方运行时依赖，同时兼容 Markdown、Obsidian wikilink 和 Frontmatter。完整 YAML 解析与原样保留是不同目标。

## 提案

- 只解析明确声明的 YAML 子集。
- 未知键和未知语法保留原始字节。
- 对不能安全解析的 Frontmatter，读取/索引可以降级，属性写入必须拒绝。
- 写入只修改目标字节区间，保留 BOM、换行、键顺序和未修改内容。
- 结构解析失败不得重写整篇文档。

## 验证

MD-001 至 MD-012；每个写入测试比较修改区域之外的字节哈希。
