# 代码类知识库的内容边界

代码仓库和知识库承担不同职责。代码仓库保存可执行源文件、完整配置、提交历史和构建产物，知识库保存帮助 Agent 理解和导航代码的派生事实。知识库页面必须能够回链到仓库、提交和文件位置，代码仓库始终是代码事实的权威来源。

## 可以进入知识库的内容

- 项目用途、边界、模块职责和目录结构；
- 对外 API、命令、配置项、环境要求和部署步骤；
- ADR、设计决策、约束、已知限制和迁移说明；
- 测试、CI、发布状态和失败摘要；
- 依赖、许可证、版本兼容性和安全修复摘要；
- commit、PR 或 issue 的变更摘要及影响范围；
- 从代码静态分析得到的入口、调用关系和数据流概览；
- 与用户工作相关的操作手册、排障步骤和经验结论。

## 不应进入知识库的内容

- 完整源代码、二进制、构建目录和大段生成日志；
- 密钥、令牌、个人隐私和未经授权的会话原文；
- 没有仓库路径、commit 或测试证据的代码断言；
- 将代码摘要当成代码本身的复制品。

## 生成页约定

代码生成页放在用户配置的隔离目录，例如 `_generated/code/`。页面包含 `generated: true`、仓库地址、commit SHA、源文件路径、行号或符号、提取方式、生成时间和置信度。源文件发生变化时，页面标记为 stale 或生成新 revision，不覆盖用户维护的权威页面。

定时任务可以自动更新这些生成页。它应先比较源 hash，再执行幂等写入，并把每次变更记录到 TaskRun、ChangeEvent 和 Git diff。涉及架构结论、行为改变、冲突事实或删除的更新进入人工处理。
