# 使用手册

## 查询与记录

从[[工作空间上下文]]进入。用「知识库备份」试一次搜索。日常新增将项目、状态和证据写在笔记里。修改已有条目前先预览，查看位置和摘要，再携带计划哈希应用。

## 知识库备份

用 kbkit 的 backup create 生成 ZIP，并用 backup verify 校验。backup restore 使用新目录或空目录。需要时重建索引，再复核实际笔记和历史版本。

## 维护

手动运行 task run，并查询生成的报告。需要定期维护时，在实际使用的 Agent 宿主创建和修改计划。
